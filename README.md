# TaskFlow — консольное приложение для управления проектами

Консольное приложение на Python для управления пользователями, проектами и задачами с использованием PostgreSQL.

Проект создан для практики работы с реляционными базами данных, SQL-запросами, внешними ключами, связями между таблицами и взаимодействием Python с PostgreSQL.

## Возможности

Приложение позволяет:

- создавать пользователей;
- создавать профили пользователей;
- создавать проекты;
- добавлять пользователей в проекты;
- удалять пользователей из проектов;
- создавать задачи;
- назначать исполнителя задачи;
- изменять статус задачи;
- изменять описание проекта;
- удалять задачи;
- просматривать пользователей;
- просматривать проекты;
- просматривать задачи;
- просматривать участников проектов;
- просматривать профили пользователей.

## Структура базы данных

В базе данных используются пять основных таблиц:

### `users`

Хранит информацию о пользователях:

- `id` — идентификатор;
- `name` — имя пользователя;
- `job_title` — должность;
- `email` — электронная почта;
- `created_at` — дата создания.

### `projects`

Хранит проекты:

- `id` — идентификатор;
- `project` — название проекта;
- `description` — описание;
- `created_at` — дата создания.

### `tasks`

Хранит задачи проектов:

- `id` — идентификатор;
- `project_id` — проект, к которому относится задача;
- `task` — название задачи;
- `user_id` — назначенный исполнитель;
- `status` — статус задачи;
- `description` — описание;
- `created_at` — дата создания.

### `project_members`

Промежуточная таблица для связи пользователей и проектов.

Позволяет реализовать связь **Many-to-Many**:

```text
users N ───── N projects
       \     /
    project_members
```

Один пользователь может участвовать в нескольких проектах, а один проект может иметь нескольких пользователей.

### `user_profiles`

Дополнительная информация о пользователях.

Связь:

```text
users 1 ───── 1 user_profiles
```

## Связи таблиц

Основные связи базы данных:

```text
users
  │
  ├──── 1:1 ──── user_profiles
  │
  ├──── N:M ──── project_members ──── N:M ──── projects
  │
  └──── 1:N ──── tasks ──── N:1 ──── projects
```

Для получения связанной информации используются `JOIN`.

Например, задача может быть связана одновременно с проектом и пользователем:

```sql
SELECT
    tasks.id,
    projects.project,
    tasks.task,
    users.name
FROM tasks
JOIN projects
    ON tasks.project_id = projects.id
JOIN users
    ON tasks.user_id = users.id;
```

## Установка

### 1. Установить PostgreSQL

Необходимо установить PostgreSQL и создать базу данных.

Например:

```sql
CREATE DATABASE test_database;
```

### 2. Установить Python

Требуется Python версии **3.14 или выше**.

Проверить версию:

```bash
python3 --version
```

### 3. Создать виртуальное окружение

В директории проекта:

```bash
python3 -m venv .venv
```

Активировать его:

```bash
source .venv/bin/activate
```

### 4. Установить psycopg

```bash
pip install "psycopg[binary]"
```

### 5. Создать структуру базы данных

Файл `database.sql` содержит SQL-код для создания структуры базы данных.

Выполнить его можно через `psql`:

```bash
psql -U <username> -h 127.0.0.1 -d test_database -f database.sql
```

### 6. Настроить подключение

Перед запуском необходимо указать параметры подключения к PostgreSQL в `database.py` или использовать переменные окружения.

Не следует публиковать пароль от PostgreSQL в GitHub.

## Запуск

После установки зависимостей и настройки базы данных:

```bash
python3 main.py
```

После запуска появится консольное меню приложения.
